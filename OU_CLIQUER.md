## 🎬 Scénario de Test Complet

### Test 1: Chatbot (30 secondes)
1. ✅ Ouvrir http://localhost:4300
2. ✅ Voir icône violette en bas à droite
3. ✅ Cliquer sur l'icône
4. ✅ Taper "Comment créer un forum?"
5. ✅ Appuyer sur Entrée ou cliquer 📤
6. ✅ Voir la réponse du chatbot
7. ✅ Cliquer sur 🗑️ pour effacer
8. ✅ Confirmer l'effacement
9. ✅ Cliquer sur ✖ pour fermer

### Test 2: Upload Multimédia (2 minutes)
1. ✅ Aller sur http://localhost:4300/forums
2. ✅ Cliquer sur un forum dans la liste de gauche
3. ✅ Cliquer sur "Nouveau Message"
4. ✅ Sélectionner "Étudiant" comme type
5. ✅ Taper un message (min 10 caractères)
6. ✅ Scroller vers le bas
7. ✅ Voir la section "Ajouter des médias"
8. ✅ Cliquer sur "Choisir un fichier" pour Image
9. ✅ Sélectionner une image JPG/PNG
10. ✅ Voir "✓ nom_fichier.jpg" en vert
11. ✅ (Optionnel) Ajouter audio/document/vidéo
12. ✅ Cliquer sur "Publier"
13. ✅ Voir "Message publié avec succès!"
14. ✅ Voir "Médias téléchargés avec succès!"

### Test 3: Préférences Email (1 minute)
1. ✅ Chercher l'icône 📧 dans le header
2. ✅ Cliquer sur l'icône
3. ✅ Voir la page "/preferences"
4. ✅ Voir 7 options de notification
5. ✅ Cliquer sur un toggle pour le désactiver
6. ✅ Cliquer sur "Enregistrer les préférences"
7. ✅ Voir "Préférences enregistrées avec succès!"
8. ✅ Recharger la page
9. ✅ Vérifier que les préférences sont sauvegardées

## 🚨 Que Faire Si Ça Ne Marche Pas

### Chatbot invisible
```
1. Ouvrir la console (F12)
2. Chercher des erreurs en rouge
3. Recharger avec Ctrl+F5
4. Vérifier que le frontend tourne
```

### Section multimédia invisible
```
1. Vérifier que vous êtes en mode "Nouveau Message"
2. Scroller vers le bas dans le modal
3. Vérifier que vous n'êtes pas en mode édition
4. Recharger la page
```

### Icône email invisible
```
1. Vérifier que le header est chargé
2. Chercher entre le bouton 🌙 et 🌐
3. Zoomer/dézoomer le navigateur
4. Recharger la page
```
