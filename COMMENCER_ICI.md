# 👋 COMMENCEZ ICI !

## 🎯 Vous Voulez Tester les Fonctionnalités ?

### Suivez ces 3 étapes simples :

---

## 1️⃣ Démarrer les Services (2 minutes)

### Terminal 1 - Backend
```bash
cd forum-service
mvn spring-boot:run
```
**Attendez**: "Started ForumApplication"

### Terminal 2 - Frontend
```bash
cd angular-app/frontend/angular-app
npm start
```
**Attendez**: "Compiled successfully"

---

## 2️⃣ Ouvrir le Navigateur
```
http://localhost:4300
```

---

## 3️⃣ Chercher les 3 Fonctionnalités

### ✅ Chatbot
**Où**: Coin inférieur droit (icône violette 🤖)  
**Action**: Cliquez et tapez une question

### ✅ Upload Multimédia
**Où**: Page `/forums` > Nouveau Message > Section "Ajouter des médias"  
**Action**: Sélectionnez un fichier et publiez

### ✅ Préférences Email
**Où**: Header en haut > Icône 📧 (entre 🌙 et 🌐)  
**Action**: Cliquez et configurez vos préférences

---

## 🎉 C'est Tout !

Si vous voyez les 3 fonctionnalités, **c'est réussi** ! 🎊

## 🚨 Problèmes Courants

### Le chatbot n'apparaît pas
```bash
# Rechargez le navigateur
Ctrl + F5
```

### La section upload est invisible
```bash
# Assurez-vous d'être en mode "Nouveau Message"
# Pas en mode édition
```

### L'icône email est invisible
```bash
# Cherchez entre le bouton 🌙 et 🌐
# Zoomez/dézoomez si nécessaire
```
