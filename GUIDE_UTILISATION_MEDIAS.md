## 🎬 Comment Utiliser (Étape par Étape)

### Étape 1: Créer un Message avec Médias (5 min)

#### 1.1 Aller sur les Forums
```
http://localhost:4300/forums
```

#### 1.2 Sélectionner un Forum
- Cliquez sur un forum dans la liste de gauche
- Exemple: "Forum de Jungle"

#### 1.3 Créer un Nouveau Message
1. Cliquez sur le bouton vert **"Nouveau Message"**
2. Remplissez le formulaire:
   - Type d'auteur: Étudiant
   - Message: "Test d'upload de médias"

#### 1.4 Ajouter des Médias
**Scrollez vers le bas** jusqu'à la section **"Ajouter des médias (optionnel)"**

**Option 1: Image** 📷
```
1. Cliquez sur "Choisir un fichier" sous "Image"
2. Sélectionnez une image (JPG, PNG, GIF, WebP)
3. Max 5MB
4. Vous verrez: "✓ nom_fichier.jpg"
```

**Option 2: Audio** 🎵
```
1. Cliquez sur "Choisir un fichier" sous "Audio"
2. Sélectionnez un fichier audio (MP3, WAV, OGG)
3. Max 10MB
4. Vous verrez: "✓ nom_fichier.mp3"
```
