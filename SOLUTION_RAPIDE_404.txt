    SOLUTION RAPIDE - ERREUR 404 SWAGGER
═══════════════════════════════════════════════════════════

❌ ERREUR : localhost:8082/swagger-ui.html → 404

✅ SOLUTION EN 3 ÉTAPES :

1️⃣ ARRÊTER LE SERVICE
   → Appuyez sur Ctrl + C dans le terminal

2️⃣ RECOMPILER
   → cd forum-service
   → mvnw clean install

3️⃣ REDÉMARRER
   → mvnw spring-boot:run

4️⃣ UTILISER LA BONNE URL
   → http://localhost:8082/swagger-ui/index.html
   
   ⚠️ ATTENTION : /swagger-ui/index.html (pas .html seul)


═══════════════════════════════════════════════════════════
    URLS À ESSAYER (DANS L'ORDRE)

    VÉRIFICATION RAPIDE
═══════════════════════════════════════════════════════════

Avant Swagger, testez que l'API fonctionne :

Si erreur 404 → Le service ne fonctionne pas ❌
